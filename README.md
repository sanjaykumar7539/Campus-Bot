# 🧠 CampusMind - AI Campus Assistant

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![GitHub](https://img.shields.io/badge/Repository-sanjaykumar7539-black.svg?logo=github)](https://github.com/sanjaykumar7539/Campus-Bot)

Enterprise-grade AI campus assistant engineered with Hybrid Retrieval-Augmented Generation (RAG), real-time WebSocket audio streaming, Faster-Whisper, and dynamic knowledge graph integration.

---

## 🌟 Key Features
* 🔍 **Hybrid RAG Pipeline:** Combines dense vector search with sparse keyword matching.
* 🎙️ **Real-Time Voice Streaming:** Powered by Faster-Whisper, Silero VAD, and Edge-TTS over WebSockets.
* 🎓 **Multi-Institution Scope:** Dynamic indexing for admissions, COE regulations, and academic guides.
* 🔒 **Security-First Architecture:** Strict environment variable isolation and sanitized repository tracking.

---

## 🛠️ Tech Stack
* **Backend:** Python 3.10+, FastAPI, PyTorch, FAISS, LangChain
* **Frontend:** React.js, Vite, Tailwind CSS
* **Speech & AI:** Faster-Whisper, Silero VAD, Edge-TTS
