# College question coverage

The answer pipeline now expands topical questions instead of always expanding
college names toward courses, rankings and admissions. Hostel, placement,
transport, library/labs/facilities, faculty, scholarship, examinations,
news/events, admissions, fees and course questions have local topic aliases.
Common Tanglish wording and selected Tamil terms are covered by tests.
This is keyword/phrase support, not a measured claim of full Tamil fluency.

The formatter retains the corresponding sections and general scoped facts.
A named college request still uses only that college's evidence. Tamil aliases
also preserve ownership for engineering, pharmacy, nursing, polytechnic,
school, and arts/science questions.

Coverage depends on the indexed records. Unknown, ambiguous or unsupported
details must receive the fallback. Do not promise every college detail or
invent amounts, dates, contact information or placement statistics.

The project was found at D:/Project/Campus rather than D:/Campus. Old absolute
D:/Campus references in .env were adjusted to the current project location.
Restart a running server to load these code and environment changes.
